# Best Times to Be Available

A one-page guide for TalkAbroad conversation partners. It shows when students book conversations for each language team, converted to the partner's own time zone, so conversation partners can open their calendars at the hours that fill.

- Pick a language team and a time zone; the page remembers both.
- English / Español toggle at the top.
- Link straight to a team: add `#french`, `#german`, etc. to the URL. Add `es-` for the Spanish page, e.g. `#es-spanish`.

Data: conversations held January 1 – November 5, 2026 (canceled conversations excluded), stored only as relative shares (each team’s busiest hour and busiest month = 100), not counts. No student or partner information is included.

The whole site is `index.html`; there is no build step.
